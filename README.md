# Armaan Verma — Portfolio

A personal portfolio showcasing projects, design work, and skills, along with a resume and contact details. It also includes dedicated pages for individual projects and information about the site.

## Run locally

You’ll need Node.js 18.18 or newer and npm.

```bash
npm install
npm run dev
```

Open the local address printed in your terminal (usually `http://localhost:5173`).

To make a production build, run `npm run build`. To preview that build locally, run `npm run preview`.
